| Сессии с окончанием раньше начала | 4 |

Полные дубли удаляются по бизнес-ключу с помощью `ROW_NUMBER`.

Записи с нарушенными обязательными связями и невозможной хронологией не попадают в `clean`.

Транзакции с корректным счётом и суммой сохраняются даже при неполной карточной детализации. Некорректная ссылка на карту заменяется на `NULL`, а полнота ссылки фиксируется полем `card_reference_complete`.

Пустые значения `income_band`, `risk_score`, `closed_at`, `activated_at`, `card_id` и `merchant_id` сохраняются, когда они допустимы по смыслу поля.
